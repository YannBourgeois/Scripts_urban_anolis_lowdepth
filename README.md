## Scripts for analyzing low-depth sequencing data for urban anoles from New Orleans

This repository will ultimately contain a set of bash scripts and Quarto documents to reproduce population genomic analyses of green anoles. 
This should look better over time. Each folder should correspond to one of the analyses shown in the following paper: https://www.authorea.com/doi/full/10.22541/au.173868007.73025099/v1
